## Verification rules applied
- Every table row links an **official** source (Michelin press release, property booking engines, venue sites).
- Values not confirmable from an official source are **left blank and flagged** — never inferred.
- Prices sampled **2026-11-25** from live booking engines; totals are arithmetic on listed rates (taxes excluded).
- Michelin star status is the **current 2026 Southwest guide** (not the 2008–09 era).

## Headline findings
- **Cheapest week = the preferred week** (Feb 15–22, 2027): verified at every property checked (Flamingo $595/7n → Wynn $4,739/7n, incl. resort fees).

- 24 Michelin restaurants; 4 currently starred (Restaurant de Joël Robuchon 2★; Guy Savoy, é by José Andrés, L'Atelier de Joël Robuchon 1★).
